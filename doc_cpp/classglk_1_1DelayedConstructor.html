Detailed Description

Drawable that constructs the actual drawable on the first draw() call. This allows creating a drawable in a thread without an OpenGL context (e.g., to pass it to AsyncLightViewer), while the OpenGL resources are created in the rendering thread.

Note
The factory is called at most once. If it throws, an error is printed and nothing is drawn afterward.
