Detailed Description

GridMap is a drawable that represents a 2D grid map with color values. It assumes that pixel values are stored in row-major order (values[y * width + x]), starting from the (-x, -y) corner (i.e., the first row lies at -y). The grid map lies on the XY plane, and the center is at the origin (0, 0, 0), thus it extends from (-resolution * width / 2, -resolution * height / 2) to (resolution * width / 2, resolution * height / 2). Use guik::TextureColor as shader setting.

enum class glk::GridMap::ColorMode
strong

ColorMode defines how the color values are interpreted.

Assuming N=width*height For uint8 values: RAW: expects |values|=N, and rgb[i] = values[i] TURBO: expects |values|=N, and rgb[i] = colormap(TURBO, values[i]) PROB: expects |values|=N, and rgb[i] = 100 - values[i] PROB_TURBO: expects |values|=N, and rgb[i] = colormap(TURBO, (100 - values[i]) * 255.0 / 100.0) RGBA: expects |values|=4*N, and rgba[i] = values[i*4:i*4+4] For float values: RAW: expects |values|=N, and rgb[i] = scale * values[i] TURBO: expects |values|=N, and rgb[i] = colormapf(TURBO, scale * values[i]) PROB: expects |values|=N, and rgb[i] = 1.0 - scale * values[i] PROB_TURBO: expects |values|=N, and rgb[i] = colormapf(TURBO, 1.0 - scale * values[i]) RGBA: expects |values|=4*N, and rgba[i] = values[i*4:i*4+4] (scale is not applied)
