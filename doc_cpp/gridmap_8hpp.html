class  glk::GridMap
 GridMap is a drawable that represents a 2D grid map with color values. It assumes that pixel values are stored in row-major order (values[y * width + x]), starting from the (-x, -y) corner (i.e., the first row lies at -y). The grid map lies on the XY plane, and the center is at the origin (0, 0, 0), thus it extends from (-resolution * width / 2, -resolution * height / 2) to (resolution * width / 2, resolution * height / 2).
