class pyridescence.glk.GridMap(*args, **kwargs)

Bases: Drawable

Drawable that represents a 2D grid map with color values.

values is a (height, width) array ((height, width, 4) for RGBA mode), and values[y, x] is the value of cell (x, y). The first row (values[0, :]) lies at -y. The grid map lies on the XY plane, and the center is at the origin (0, 0, 0), thus it extends from (-resolution * width / 2, -resolution * height / 2) to (resolution * width / 2, resolution * height / 2). Use guik.TextureColor as shader setting.

uint8 arrays use the uint8 interpretation of ColorMode, and arrays of other dtypes are converted to float32 and use the float interpretation.

class ColorMode(self: pyridescence.glk.GridMap.ColorMode, value: int)

Bases: pybind11_object

Defines how the color values are interpreted.

For uint8 values:

RAW: rgb = values[y, x] TURBO: rgb = colormap(TURBO, values[y, x]) PROB: rgb = 100 - values[y, x] PROB_TURBO: rgb = colormap(TURBO, (100 - values[y, x]) * 255.0 / 100.0) RGBA: rgba = values[y, x, :]

For float values:

RAW: rgb = scale * values[y, x] TURBO: rgb = colormapf(TURBO, scale * values[y, x]) PROB: rgb = 1.0 - scale * values[y, x] PROB_TURBO: rgb = colormapf(TURBO, 1.0 - scale * values[y, x]) RGBA: rgba = values[y, x, :] (scale is not applied)

2D OpenGL texture. All methods must be called in the thread that owns the OpenGL context. Pixel data are assumed to be tightly packed (no row padding).

Create a texture from raw pixel data.

Parameters:

  • size – Texture size (width, height).

  • internal_format – Internal format of the texture (e.g., gl.RGBA8, gl.RGBA32F).

  • format – Format of the pixel data (e.g., gl.RGBA, gl.RGB, gl.RED).

  • type – Data type of the pixel data (e.g., gl.UNSIGNED_BYTE, gl.FLOAT).

  • bytes – Pixel data as an object supporting the buffer protocol (e.g., numpy array, bytes, bytearray). The first row is uploaded as the first (v=0) row of the texture. If empty, the texture is created but not initialized.

Read the pixel data (mip level 0) from the texture.

Parameters:

  • format – Format of the pixel data to read (e.g., gl.RGBA, gl.RGB, gl.RED, gl.DEPTH_COMPONENT, gl.RGBA_INTEGER).

  • type –

    Data type of the pixel data to read. It determines the dtype of the returned array (UNSIGNED_BYTE: uint8, BYTE: int8, UNSIGNED_SHORT: uint16, SHORT: int16, HALF_FLOAT: float16,

    UNSIGNED_INT: uint32, INT: int32, FLOAT: float32).

  • num_components – Number of components per pixel. If <= 0, it is derived from format.

Returns:

Array of shape (height, width, num_components), or (height, width) if num_components is 1. The first row is the first (v=0) row of the texture. For the viewer’s frame buffers, it is the bottom row of the screen.
